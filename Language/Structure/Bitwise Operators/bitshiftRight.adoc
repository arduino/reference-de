= >> Bitshift rechts


// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
Der Right-Shift-Operator `>>` bewirkt, dass die Bits des linken Operanden um die durch den rechten Operanden angegebene Anzahl von Positionen *nach rechts* verschoben werden.
[%hardbreaks]


[float]
=== Syntax
`variable >> number_of_bits`


[float]
=== Parameter
`variable`: Erlaubte Datentypen: jeder Ganzzahltyp (`byte`, `short`, `int`, `long`, `unsigned short`...). +
`number_of_bits`: Eine positive Zahl, die kleiner als die Bitbreite von `variable` ist. Erlaubte Datentypen: `int`.


--

[float]
=== Beispielcode

[source,arduino]
----
int a = 40;     // Binär: 0000000000101000
int b = a >> 3; // Binär: 0000000000000101, dezimal: 5
----
[%hardbreaks]

[float]
=== Anmerkungen und Warnungen
Wenn du `x` um `y` Bits nach rechts verschiebst (`x >> y`), "fallen" die `y` am weitesten rechts liegenden Bits von `x` heraus und werden verworfen.
Hat `x` einen vorzeichenlosen Typ (z. B. `unsigned int`), werden die `y` am weitesten links liegenden Bits des Ergebnisses mit Nullen aufgefüllt.
Hat `x` einen vorzeichenbehafteten Typ (z. B. `int`), ist sein am weitesten links liegendes Bit das Vorzeichenbit, das bestimmt, ob der Wert positiv oder negativ ist.
In diesem Fall werden die `y` am weitesten links liegenden Bits des Ergebnisses mit Kopien des Vorzeichenbits aufgefüllt.
Dieses Verhalten, "Vorzeichenerweiterung" genannt, sorgt dafür, dass das Ergebnis dasselbe Vorzeichen wie `x` hat.

[source,arduino]
----
int x = -16;          // Binär: 1111111111110000
int y = 3;
int result = x >> y;  // Binär: 1111111111111110, dezimal: -2
----
Das ist möglicherweise nicht das gewünschte Verhalten.
Wenn stattdessen Nullen von links nachgeschoben werden sollen, kannst du eine Typumwandlung verwenden, um die Vorzeichenerweiterung zu unterdrücken:

[source,arduino]
----
int x = -16;                        // Binär: 1111111111110000
int y = 3;
int result = (unsigned int)x >> y;  // Binär: 0001111111111110, dezimal: 8190
----
Durch die Vorzeichenerweiterung führt der Right-Shift-Operator `>>` eine Division durch Potenzen von 2 aus, auch bei negativen Zahlen. Zum Beispiel:

[source,arduino]
----
int x = -1000;
int y = x >> 3; // Integer-Division von -1000 durch 8, ergibt y = -125.
----
Beachte aber die Rundung bei negativen Zahlen:
[source,arduino]
----
int x = -1001;
int y = x >> 3; // Division durch Verschieben rundet immer ab, ergibt y = -126
int z = x / 8;  // Divisionsoperator rundet in Richtung null, ergibt z = -125
----
