= % Rest


// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
Die *Rest*-Operation berechnet den Rest, wenn eine ganze Zahl durch eine andere geteilt wird.
Dies ist nützlich, um eine Variable innerhalb eines bestimmten Bereichs zu halten (z. B. die Größe eines Arrays).
Das Symbol `%` (Prozent) wird zur Ausführung der Rest-Operation verwendet.
[%hardbreaks]


[float]
=== Syntax
`remainder = dividend % divisor;`


[float]
=== Parameter
`remainder`: Variable. Erlaubte Datentypen: `int`, `float`, `double`. +
`dividend`: Variable oder Konstante. Erlaubte Datentypen: `int`. +
`divisor`: *Nicht null* Variable oder Konstante. Erlaubte Datentypen: `int`.


--

[float]
=== Beispielcode

[source,arduino]
----
int x = 0;
x = 7 % 5;  // x enthält jetzt 2
x = 9 % 5;  // x enthält jetzt 4
x = 5 % 5;  // x enthält jetzt 0
x = 4 % 5;  // x enthält jetzt 4
x = -4 % 5; // x enthält jetzt -4
x = 4 % -5; // x enthält jetzt 4
----

[source,arduino]
----
/* Aktualisieren eines Werts in einem Array durch eine Schleife */

int values[10];
int i = 0;

void setup() {}

void loop() {
  values[i] = analogRead(0);
  i = (i + 1) % 10; // Rest-Operator lässt die Variable wieder bei 0 beginnen
}
----
[%hardbreaks]

[float]
=== Anmerkungen und Warnungen
1. Der Rest-Operator arbeitet nicht mit `float`-Werten.

2. Wenn der *erste* Operand negativ ist, ist das Ergebnis negativ (oder null).
Daher liegt das Ergebnis von `x % 10` nicht immer zwischen 0 und 9, wenn `x` negativ sein kann.
[%hardbreaks]
