= Keyboard.begin()


// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
Wenn die Funktion mit einem Leonardo- oder Due-Board benutzt wird, startet `Keyboard.begin()` eine Tastaturemulation auf dem verbundenen Computer. Zum Beenden benutze link:../keyboardend[Keyboard.end()].
[%hardbreaks]


[float]
=== Syntax
`Keyboard.begin()` +
`Keyboard.begin(layout)`


[float]
=== Parameter
`layout`: Das zu verwendende Tastaturlayout. Dieser Parameter ist optional, der Standardwert ist `KeyboardLayout_en_US`.


[float]
=== Tastaturlayouts
Die Bibliothek unterstützt derzeit die folgenden nationalen Tastaturlayouts:

* `KeyboardLayout_da_DK`: Dänemark
* `KeyboardLayout_de_DE`: Deutschland
* `KeyboardLayout_en_US`: USA
* `KeyboardLayout_es_ES`: Spanien
* `KeyboardLayout_fr_FR`: Frankreich
* `KeyboardLayout_hu_HU`: Ungarn
* `KeyboardLayout_it_IT`: Italien
* `KeyboardLayout_pt_PT`: Portugal
* `KeyboardLayout_sv_SE`: Schweden


[float]
=== Rückgabewert
Nichts.

=== Beispielcode
// Beschreibe, worum es im Beispielcode geht und füge relevanten Code hinzu.   ►►►►► DIESER ABSCHNITT IST VERPFLICHTEND ◄◄◄◄◄

Sendet eine Nachricht über die Keyboard-Bibliothek, wenn der angeschlossene Button gedrückt wird.

[source,arduino]
----
#include <Keyboard.h>

void setup() {
  // Pin 2 wird ein Inputpin mit Pullup-Widerstand.
  // Pin 2 ist damit immer high, bis er auf Ground
  // verbunden wird:
  pinMode(2, INPUT_PULLUP);
  Keyboard.begin();
}

void loop() {
  //Wenn der Button gedrückt wird
  if(digitalRead(2) == LOW){
    //Sende die Nachricht
    Keyboard.print("Hello!");
  }
}
----


[float]
=== Anmerkungen und Warnungen
Eigene Layouts kannst du erstellen, indem du ein bestehendes Layout kopierst und anpasst. Die Anleitung dazu steht in der Datei KeyboardLayout.h der Keyboard-Bibliothek.
