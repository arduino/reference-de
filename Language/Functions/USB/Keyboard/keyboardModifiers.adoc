= Modifikatortasten und Sondertasten


// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
Wenn du den Funktionen `Keyboard.write()`, `Keyboard.press()` und `Keyboard.release()` ein druckbares ASCII-Zeichen als Argument übergibst, simulieren sie das Betätigen der entsprechenden Tasten. Diese Funktionen können auch ASCII-Zeichen verarbeiten, für die eine Taste zusammen mit Shift oder, auf internationalen Tastaturen, AltGr gedrückt werden muss. Zum Beispiel:
[source,arduino]
----
Keyboard.write('a');  // Taste 'A' drücken und loslassen
Keyboard.write('A');  // Shift und 'A' drücken, dann beide loslassen
----
Eine typische Tastatur hat aber viele Tasten, die keinem druckbaren ASCII-Zeichen entsprechen. Um diese Tasten zu simulieren, stellt die Bibliothek eine Reihe von Makros bereit, die du `Keyboard.write()`, `Keyboard.press()` und `Keyboard.release()` als Argument übergeben kannst. Die Tastenkombination Shift+F2 erzeugst du zum Beispiel so:
[source,arduino]
----
Keyboard.press(KEY_LEFT_SHIFT);  // Shift drücken und halten
Keyboard.press(KEY_F2);          // F2 drücken und halten
Keyboard.releaseAll();           // Beide loslassen
----
Beachte: Um mehrere Tasten gleichzeitig zu drücken, musst du link:../keyboardpress[`Keyboard.press()`] statt link:../keyboardwrite[`Keyboard.write()`] verwenden, denn `Keyboard.write()` „tippt“ die Tasten nur an (es drückt sie und lässt sie sofort wieder los).
[%hardbreaks]
Die verfügbaren Makros sind unten aufgelistet:

[float]
==== Internationale Tastaturlayouts

Einige nationale Layouts definieren zusätzliche Tasten. Das schwedische und das dänische Layout definieren zum Beispiel `KEY_A_RING` als `0xB7`. Das ist die Taste rechts neben „P“, die auf diesen Layouts mit „Å“ und auf dem US-Layout mit „{“/„[“ beschriftet ist. Um diese Definitionen zu verwenden, musst du die passende Datei Keyboard_*.h einbinden. Zum Beispiel:

[source,arduino]
----
#include <Keyboard.h>
#include <Keyboard_sv_SE.h> // Zusätzliche Tastendefinitionen des schwedischen Layouts

void setup() {
  Keyboard.begin(KeyboardLayout_sv_SE); // Schwedisches Layout verwenden
  Keyboard.write(KEY_A_RING);
}

void loop() {} // Schleife, die nichts tut
----

Die Liste der layoutspezifischen Tastendefinitionen findest du in der jeweiligen Datei Keyboard_*.h in den Quellen der Bibliothek.
