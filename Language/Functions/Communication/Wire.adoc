= Wire


// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung


Mit dieser Bibliothek kannst du mit I2C-Geräten kommunizieren. I2C steht auf allen Arduino-Boards zur Verfügung. I2C ist ein sehr verbreitetes Protokoll, das vor allem zum Lesen und Senden von Daten von und zu externen I2C-Komponenten verwendet wird. Mehr dazu erfährst du in link:https://docs.arduino.cc/learn/communication/wire[diesem Artikel zu Arduino & I2C].

Aufgrund des Hardware-Designs und verschiedener Unterschiede in der Architektur liegen die I2C-Pins an unterschiedlichen Stellen. Die folgende Pin-Übersicht zeigt die Standard-Pins sowie zusätzliche Anschlüsse, die auf bestimmten Boards verfügbar sind.


|================================================================================================================================================
| Board                               | I2C-Standard        | I2C1                      | I2C2                 | Hinweise
| UNO R3, UNO R3 SMD, UNO Mini Ltd    | A4(SDA), A5(SCL)    |                           |                      | I2C ist auch über die SDA/SCL-Pins (digitaler Header) verfügbar.
| UNO R4 Minima, UNO R4 WiFi          | A4(SDA), A5(SCL)    | Qwiic: D27(SDA), D26(SCL) |                      | I2C ist auch über die SDA/SCL-Pins (digitaler Header) verfügbar.
| UNO WiFi Rev2, Zero                 | 20(SDA), 21(SCL)    |                           |                      |
| Leonardo, Micro, Yún Rev2           | D2(SDA), D3(SCL)    |                           |                      |
| Nano-Boards                         | A4(SDA), A5(SCL)    |                           |                      |
| MKR-Boards                          | D11(SDA), D12(SCL)  |                           |                      |
| GIGA R1 WiFi                        | 20(SDA), 21(SCL)    |  D102(SDA1), D101 (SCL1)  | D9(SDA2), D8 (SCL2)  | Verwende `Wire1.begin()` für I2C1 und `Wire2.begin()` für I2C2.
| Due                                 | 20(SDA), 21(SCL)    |  D70(SDA1), D71(SCL1)     |                      | Verwende `Wire1.begin()` für I2C1.
| Mega 2560 Rev3                      | D20(SDA), D21(SCL)  |                           |                      |
|================================================================================================================================================


Diese Bibliothek erbt von den Stream-Funktionen und verhält sich damit wie andere Bibliotheken zum Lesen und Schreiben. Deshalb wurden `send()` und `receive()` durch `read()` und `write()` ersetzt.

Neuere Versionen der Wire-Bibliothek können Timeouts verwenden, um bei bestimmten Problemen auf dem Bus ein Hängenbleiben zu verhindern. In aktuellen Versionen ist das aber (noch) nicht standardmäßig aktiviert. Es wird empfohlen, diese Timeouts bei der Verwendung der Wire-Bibliothek immer zu aktivieren. Weitere Details findest du bei der Funktion Wire.setWireTimeout.

*Hinweis:* Es gibt I2C-Adressen in einer 7-Bit- und einer 8-Bit-Variante. 7 Bits identifizieren das Gerät, und das achte Bit legt fest, ob auf das Gerät geschrieben oder von ihm gelesen wird. Die Wire-Bibliothek verwendet durchgehend 7-Bit-Adressen. Wenn dein Datenblatt oder Beispielcode eine 8-Bit-Adresse verwendet, lässt du das niederwertigste Bit weg (verschiebst den Wert also um ein Bit nach rechts) und erhältst eine Adresse zwischen 0 und 127. Die Adressen 0 bis 7 werden allerdings nicht verwendet, weil sie reserviert sind. Die erste nutzbare Adresse ist daher 8. Beachte, dass beim Anschließen der SDA/SCL-Pins ein Pullup-Widerstand benötigt wird. Weitere Informationen findest du in den Beispielen. Das MEGA-2560-Board hat Pullup-Widerstände an den Pins 20 und 21 direkt auf der Platine.

*Die Wire-Bibliothek verwendet einen 32-Byte-Puffer, daher muss jede Kommunikation innerhalb dieser Grenze bleiben. Überzählige Bytes einer einzelnen Übertragung werden einfach verworfen.*

So verwendest du diese Bibliothek:

`#include <Wire.h>`
