= SPI


// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
Mit dieser Bibliothek kannst du mit SPI-Geräten kommunizieren, der Arduino arbeitet dabei als Controller. Die Bibliothek ist in jeder Arduino-Plattform (avr, megaavr, mbed, samd, sam, arc32) enthalten, *du musst sie also nicht separat installieren*.

Um die Bibliothek zu verwenden, binde sie so ein:

`#include <SPI.h>`

Mehr über Arduino und SPI erfährst du in der Anleitung https://docs.arduino.cc/learn/communication/spi[Arduino & Serial Peripheral Interface (SPI)].

--
