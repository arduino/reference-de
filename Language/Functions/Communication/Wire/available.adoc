= available

// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
Diese Funktion gibt die Anzahl der Bytes zurück, die mit `read()` abgerufen werden können. Sie sollte auf einem Controller nach einem Aufruf von `requestFrom()` oder auf einem Peripheriegerät innerhalb des `onReceive()`-Handlers aufgerufen werden. `available()` erbt von der Stream-Dienstklasse.

[float]
=== Syntax
`Wire.available()`

[float]
=== Parameter

Keine.

[float]
=== Rückgabewert

Die Anzahl der zum Lesen verfügbaren Bytes.
