= onReceive

// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung

Diese Funktion registriert eine Funktion, die aufgerufen wird, wenn ein Peripheriegerät eine Übertragung von einem Controller empfängt.

[float]
=== Syntax
`Wire.onReceive(handler)`

[float]
=== Parameter

* _handler_: die Funktion, die aufgerufen wird, wenn das Peripheriegerät Daten empfängt. Sie sollte einen einzelnen `int`-Parameter haben (die Anzahl der vom Controller gelesenen Bytes) und nichts zurückgeben.

[float]
=== Rückgabewert

Nichts.
