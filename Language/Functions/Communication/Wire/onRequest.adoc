= onRequest

// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
Diese Funktion registriert eine Funktion, die aufgerufen wird, wenn ein Controller Daten von einem Peripheriegerät anfordert.

[float]
=== Syntax
`Wire.onRequest(handler)`

[float]
=== Parameter

* _handler_: die aufzurufende Funktion. Sie hat keine Parameter und gibt nichts zurück.

[float]
=== Rückgabewert

Nichts.
