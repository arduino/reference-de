= write

// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
Diese Funktion schreibt Daten von einem Peripheriegerät als Antwort auf eine Anforderung eines Controllers oder stellt Bytes für die Übertragung von einem Controller an ein Peripheriegerät in die Warteschlange (zwischen den Aufrufen von `beginTransmission()` und `endTransmission()`).

[float]
=== Syntax
`Wire.write(value)`

`Wire.write(string)`

`Wire.write(data, length)`

[float]
=== Parameter
* _value_: ein Wert, der als einzelnes Byte gesendet wird.
* _string_: eine Zeichenfolge, die als Folge von Bytes gesendet wird.
* _data_: ein Array mit Daten, die als Bytes gesendet werden.
* _length_: die Anzahl der zu übertragenden Bytes.

[float]
=== Rückgabewert

Die Anzahl der geschriebenen Bytes (diese Zahl auszulesen ist optional).

[float]
=== Beispielcode

[source,arduino]
----
#include <Wire.h>

byte val = 0;

void setup() {
  Wire.begin(); // I2C-Bus beitreten
}

void loop() {
    Wire.beginTransmission(44);  // An Gerät Nummer 44 (0x2C) übertragen

    Wire.write(val);             // Wert-Byte senden
    Wire.endTransmission();      // Übertragung beenden

    val++;                       // Wert erhöhen

    // Wenn die 64. Position (Maximum) erreicht ist
    if(val == 64) {
        val = 0;                   // Wieder beim niedrigsten Wert beginnen
    }

    delay(500);
}
----
