= beginTransmission

// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
Diese Funktion beginnt eine Übertragung an das I2C-Peripheriegerät mit der angegebenen Adresse. Anschließend stellst du mit der Funktion `write()` Bytes für die Übertragung in die Warteschlange und überträgst sie mit einem Aufruf von `endTransmission()`.

[float]
=== Syntax

`Wire.beginTransmission(address)`

[float]
=== Parameter
* _address_: die 7-Bit-Adresse des Geräts, an das übertragen werden soll.

[float]
=== Rückgabewert
Nichts.
