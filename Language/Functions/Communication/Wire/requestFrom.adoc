= requestFrom

[#overview]
--

[float]
=== Beschreibung
Diese Funktion wird vom Controller verwendet, um Bytes von einem Peripheriegerät anzufordern. Die Bytes können dann mit den Funktionen `available()` und `read()` abgerufen werden. Die Methode `requestFrom()` akzeptiert ein boolesches Argument, das ihr Verhalten für die Kompatibilität mit bestimmten I2C-Geräten ändert. Bei true sendet `requestFrom()` nach der Anforderung eine Stopp-Nachricht und gibt den I2C-Bus frei. Bei false sendet `requestFrom()` nach der Anforderung eine Restart-Nachricht. Der Bus wird dann nicht freigegeben, sodass kein anderer Controller zwischen den Nachrichten Daten anfordern kann. So kann ein Controller mehrere Anforderungen senden, solange er den Bus kontrolliert. Der Standardwert ist true.

[float]
=== Syntax
`Wire.requestFrom(address, quantity)`

`Wire.requestFrom(address, quantity, stop)`

[float]
=== Parameter
* _address_: die 7-Bit-Adresse des Peripheriegeräts, von dem Bytes angefordert werden.
* _quantity_: die Anzahl der anzufordernden Bytes.
* _stop_: true oder false. Bei true wird nach der Anforderung eine Stopp-Nachricht gesendet und der Bus freigegeben. Bei false wird nach der Anforderung fortlaufend ein Restart gesendet und die Verbindung bleibt aktiv.

[float]
=== Rückgabewert
* _byte_: die Anzahl der vom Peripheriegerät zurückgegebenen Bytes.
