= SPI.usingInterrupt()

// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung

Wenn dein Sketch SPI-Transaktionen innerhalb eines Interrupts ausführt, rufe diese Funktion auf, um die Nummer oder den Namen des Interrupts bei der SPI-Bibliothek zu registrieren. So kann `SPI.beginTransaction()` Konflikte bei der Nutzung verhindern. Beachte, dass der beim Aufruf von `usingInterrupt()` angegebene Interrupt durch `beginTransaction()` deaktiviert und durch `endTransaction()` wieder aktiviert wird.

[float]
=== Syntax

`SPI.usingInterrupt(interruptNumber)`


[float]
=== Parameter

interruptNumber: die zugehörige Interrupt-Nummer.

[float]
=== Rückgabewert
Nichts.
