= SPI.endTransaction()


// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
Beendet die Nutzung des SPI-Busses. Normalerweise wird die Funktion aufgerufen, nachdem das Chip-Select-Signal zurückgenommen wurde, damit andere Bibliotheken den SPI-Bus verwenden können.


[float]
=== Syntax
`SPI.endTransaction()`


[float]
=== Parameter
Keine.


[float]
=== Rückgabewert
Nichts.
