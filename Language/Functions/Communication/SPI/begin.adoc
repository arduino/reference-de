= SPI.begin()


// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
Initialisiert den SPI-Bus: SCK, MOSI und SS werden als Ausgänge gesetzt, SCK und MOSI auf LOW und SS auf HIGH gezogen.


[float]
=== Syntax
`SPI.begin()`


[float]
=== Parameter
Keine.


[float]
=== Rückgabewert
Nichts.
