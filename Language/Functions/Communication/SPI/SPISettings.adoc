= SPISettings


// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
Mit dem Objekt `SPISettings` konfigurierst du den SPI-Port für dein SPI-Gerät. Alle 3 Parameter werden in einem einzigen `SPISettings`-Objekt zusammengefasst, das an `SPI.beginTransaction()` übergeben wird.

Wenn alle deine Einstellungen Konstanten sind, solltest du SPISettings direkt in `SPI.beginTransaction()` verwenden, siehe den Abschnitt Syntax unten. Bei Konstanten ergibt diese Schreibweise kleineren und schnelleren Code.

Wenn eine deiner Einstellungen eine Variable ist, kannst du ein SPISettings-Objekt anlegen, das die 3 Einstellungen enthält. Den Namen dieses Objekts übergibst du dann an SPI.beginTransaction(). Ein benanntes SPISettings-Objekt kann effizienter sein, wenn deine Einstellungen keine Konstanten sind, besonders wenn die maximale Geschwindigkeit eine berechnete oder konfigurierte Variable ist und keine Zahl, die du direkt in deinen Sketch schreibst.

[float]
=== Syntax
`SPI.beginTransaction(SPISettings(14000000, MSBFIRST, SPI_MODE0))`
Hinweis: Am besten, wenn alle 3 Einstellungen Konstanten sind

`SPISettings mySetting(speedMaximum, dataOrder, dataMode)`
Hinweis: Am besten, wenn eine der Einstellungen eine Variable ist


[float]
=== Parameter

`speedMaximum`: Die maximale Geschwindigkeit der Kommunikation. Für einen SPI-Chip, der für bis zu 20 MHz ausgelegt ist, verwendest du 20000000. +
`dataOrder`: MSBFIRST oder LSBFIRST +
`dataMode`: SPI_MODE0, SPI_MODE1, SPI_MODE2 oder SPI_MODE3


[float]
=== Rückgabewert
Nichts.
