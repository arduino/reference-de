= SPI.transfer()

// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung

Eine SPI-Übertragung beruht auf gleichzeitigem Senden und Empfangen: Die empfangenen Daten werden in receivedVal (bzw. receivedVal16) zurückgegeben. Bei der Übertragung eines Puffers werden die empfangenen Daten direkt im Puffer abgelegt (die alten Daten werden durch die empfangenen ersetzt).

[float]
=== Syntax

`receivedVal = SPI.transfer(val)`

`receivedVal16 = SPI.transfer16(val16)`

`SPI.transfer(buffer, size)`


[float]
=== Parameter

* val: das Byte, das über den Bus gesendet werden soll
* val16: die Zwei-Byte-Variable, die über den Bus gesendet werden soll
* buffer: das Array mit den zu übertragenden Daten


[float]
=== Rückgabewert
Die empfangenen Daten.
