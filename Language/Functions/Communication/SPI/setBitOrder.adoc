= SPI.setBitOrder()


// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
Diese Funktion sollte in neuen Projekten nicht mehr verwendet werden. Konfiguriere die SPI-Parameter stattdessen mit link:../spisettings[SPISettings] und link:../begintransaction[SPI.beginTransaction()].

Legt die Bitreihenfolge fest, in der die Bits über den SPI-Bus hinaus- und hineingeschoben werden: entweder LSBFIRST (niederwertigstes Bit zuerst) oder MSBFIRST (höchstwertiges Bit zuerst).


[float]
=== Syntax
`SPI.setBitOrder(order)`


[float]
=== Parameter
order: entweder LSBFIRST oder MSBFIRST


[float]
=== Rückgabewert
Nichts.
