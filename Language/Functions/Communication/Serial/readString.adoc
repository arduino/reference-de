= readString()


// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
`_Serial_.readString()` liest Zeichen aus dem seriellen Puffer in einen `String`. Die Funktion wird abgebrochen, wenn eine Zeitüberschreitung auftritt (siehe link:../settimeout[setTimeout()]).

`_Serial_.readString()` erbt von der link:../../stream[Stream]-Dienstklasse.
[%hardbreaks]


[float]
=== Syntax
`_Serial_.readString()`


[float]
=== Parameter
`_Serial_`: Serielles Port-Objekt. Siehe die Liste der verfügbaren seriellen Anschlüsse für jedes Board auf der link:https://www.arduino.cc/reference/de/language/functions/communication/serial/[Serial-Hauptseite].


[float]
=== Rückgabewert
Ein `String`, der aus dem seriellen Puffer gelesen wird.

--
// ÜBERSICHTSABSCHNITT ENDET


// HOW-TO-USE-ABSCHNITT STARTET
[#howtouse]
--

[float]
=== Beispielcode
Zeigt die Verwendung von `Serial.readString()`.

[source,arduino]
----
void setup() {
  Serial.begin(9600);
}

void loop() {
  Serial.println("Enter data:");
  while (Serial.available() == 0) {}     // Warten, bis Daten verfügbar sind
  String teststr = Serial.readString();  // Lesen bis zur Zeitüberschreitung
  teststr.trim();                        // Leerraum wie \r und \n am Ende des Strings entfernen
  if (teststr == "red") {
    Serial.println("A primary color");
  } else {
    Serial.println("Something else");
  }
}
----
[%hardbreaks]


[float]
=== Anmerkungen und Warnungen
Die Funktion bricht nicht vorzeitig ab, wenn die Daten Zeilenendezeichen enthalten. Der zurückgegebene `String` kann Carriage-Return- und/oder Zeilenvorschubzeichen enthalten, wenn diese empfangen wurden.
[%hardbreaks]
