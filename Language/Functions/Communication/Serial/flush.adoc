= flush()


// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
Wartet, bis die Übertragung der ausgehenden seriellen Daten abgeschlossen ist.

`flush()` erbt von der link:../../stream/streamflush[Stream]-Dienstklasse.
[%hardbreaks]


[float]
=== Syntax
`_Serial_.flush()`


[float]
=== Parameter
`_Serial_`: Serielles Port-Objekt. Siehe die Liste der verfügbaren seriellen Anschlüsse für jedes Board auf der link:https://www.arduino.cc/reference/de/language/functions/communication/serial/[Serial-Hauptseite].


[float]
=== Rückgabewert
Nichts.
