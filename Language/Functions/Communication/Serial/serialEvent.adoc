= serialEvent()


// ÜBERSICHTSABSCHNITT STARTET
[#overview]
--

[float]
=== Beschreibung
Wird am Ende von link:../../../../structure/sketch/loop[`loop()`] aufgerufen, wenn Daten verfügbar sind. Verwende `_Serial_.read()`, um diese Daten zu erfassen.

*Bitte beachte:* Die meisten modernen Boards unterstützen diese Methode nicht. Siehe "Anmerkungen und Warnungen" weiter unten auf dieser Seite.
[%hardbreaks]


[float]
=== Syntax

[source,arduino]
----
void serialEvent() {
   // Statement(s)
}
----

Die Boards Mega 2560 R3 und Due haben zusätzliche serielle Anschlüsse. Diese erreichst du, indem du die entsprechende Nummer an das Ende des Funktionsnamens anhängst.

[source,arduino]
----
void serialEvent1() {
   // Statement(s)
}

void serialEvent2() {
   // Statement(s)
}

void serialEvent3() {
   // Statement(s)
}
----


[float]
=== Parameter
`Statement(s)`: Alle gültigen Anweisungen.


[float]
=== Rückgabewert
Nichts.

--

[#howtouse]

[float]
=== Anmerkungen und Warnungen
Bitte beachte, dass `serialEvent()` auf modernen Arduino-Boards *nicht funktioniert*. Die einzigen Boards, die es nachweislich unterstützen (Stand: 06.12.2023), sind *UNO R3*, *Nano*, *Mega 2560 R3* und *Due*.

Stattdessen kannst du die Methode link:../available[`available()`] verwenden. Die Beispiele dort zeigen, wie du serielle Daten nur dann liest, wenn sie verfügbar sind, ähnlich wie `serialEvent()` implementiert ist.
[%hardbreaks]
